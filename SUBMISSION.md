# Kalvium Assignment Submission

This repository contains the completed Retrieval Metrics Mini Project.

## Implementation

- Reciprocal Rank finds the first relevant result and returns its inverse rank.
- MRR averages reciprocal rank across the 10 test queries.
- Recall@10 measures the fraction of queries with a relevant result in the top 10.
- The evaluation output compares keyword and semantic search.

## Run

```bash
node eval.js
```
